# BIXOLON Bakery Self Checkout 1.1.0 release record

## Scope

1.1.0 is an on-device Windows self-checkout prototype. Customer mode is the cold-start default and provides capture, retake, Top-3 selection, full-catalog selection, auto-result override, manual cart, durable local simulated payment, completion, and reset. Administrator mode is deliberately separate and provides dashboard, transaction history/detail, append-only review annotations, revisioned products, read-only diagnostics, and supported kiosk settings/retention. There is no account, PIN, remote service, multi-kiosk aggregation, training/calibration update, mutable inference policy, or real payment/POS integration.

## Audit and schema

- SQLite schema: **v4**.
- Migration path: fresh databases create `created_schema_v4`; v1/v2 history upgrades to v4 and preserve checkout evidence; v3 review annotations migrate with their integrity guards recreated; v4 settings entries are idempotently backfilled for interrupted upgrade fixtures.
- Reviews are append-only annotations. They cannot rewrite inference objects/candidates/scores/boxes, customer resolutions, completed orders, or payments.
- Catalog and settings use copy-on-write revisions. A session retains the catalog/settings revisions captured at session start, and final-order product name/price snapshots remain historical.
- Image retention shows a read-only preview, requires explicit confirmation for execution, verifies exact path/bytes/SHA-256 before a same-root quarantine move, retains aggregate receipts/records, and records audit/retention events.

## Known prototype limitations

- Payment is simulated only; it creates no card, PG, POS, printer, or fiscal transaction.
- Administrator entry has no authentication in 1.1.0.
- Diagnostics reports stored/current local evidence and readiness; it does not change policy thresholds or artifact verification.
- Artifact, GPU, package-distribution, performance, and external acceptance suites that cannot be run in this environment are reported as **unverified**, never passed.
