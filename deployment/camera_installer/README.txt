BIXOLON Bakery AI Evaluator 1.1.0
=================================

이 설치본은 Windows 10/11 x64 내부 평가용입니다.
Python, Flutter, Git 또는 인터넷 연결을 별도로 준비할 필요가 없습니다.

바로 실행
---------
휴대용 폴더 전체를 원하는 위치로 복사한 뒤 `bakery_camera_prototype.exe`를 더블클릭합니다.
앱과 같은 폴더의 `runtime` 및 `pipeline`을 자동으로 사용하므로 환경 변수를 설정할 필요가 없습니다.

설치 관리자 사용
----------------
1. 설치 파일의 SHA-256이 함께 전달된 `.sha256` 파일과 같은지 확인합니다.
2. 설치 파일을 실행합니다. 미서명 내부 테스트 빌드에서는 Windows SmartScreen 안내가 표시될 수 있습니다.
3. 시작 메뉴에서 "BIXOLON Bakery AI Evaluator"를 실행하거나 설치 중 선택한 바탕 화면 바로가기를 더블클릭합니다.
4. 모델 준비가 완료될 때까지 기다린 뒤 카메라 트레이를 놓고 "분석하기"를 누릅니다.

결과 해석
---------
- 확정 항목만 품목별 수량에 포함됩니다.
- "판단할 수 없음"은 등록 품목으로 자동 확정하기에 근거가 부족한 대상입니다.
- 판단할 수 없는 대상을 선택하면 확인용 Top-3 후보가 표시됩니다.
- Top-3 후보는 모든 모델 근거보다 우선하지 않으며, 임의의 등록 SKU를 확정하지 않습니다.

CPU/GPU
-------
NVIDIA GPU와 호환 드라이버가 있으면 자동으로 GPU를 사용합니다.
GPU를 사용할 수 없거나 초기화에 실패하면 같은 FP32 파이프라인을 CPU로 실행합니다.
첫 모델 준비와 분석은 CPU에서 오래 걸릴 수 있습니다.

문제 해결
---------
- 카메라를 찾지 못하면 연결 상태를 확인하고 "카메라 다시 연결"을 누릅니다.
- 모델 준비에 실패하면 앱을 종료한 뒤 `bakery_camera_prototype.exe`를 다시 더블클릭합니다.
- 계속 실패하면 설치 프로그램으로 다시 설치합니다.

제거
----
Windows 설정 > 앱 > 설치된 앱에서 "BIXOLON Bakery AI Evaluator"를 제거합니다.

주의
----
이 프로그램은 모델 성능 평가용 내부 빌드입니다. 라이브 카메라 결과만으로 POS 출하 적합성이나 운영 정확도를 판단하지 마십시오.
