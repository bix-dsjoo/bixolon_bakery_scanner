BIXOLON Bakery AI Evaluator 1.0.0
=================================

이 설치본은 Windows 10/11 x64 내부 평가용입니다.
Python, Flutter, Git 또는 인터넷 연결을 별도로 준비할 필요가 없습니다.

사용 방법
---------
1. 설치 파일의 SHA-256이 함께 전달된 .sha256 파일과 같은지 확인합니다.
2. 설치 파일을 실행합니다. 미서명 내부 테스트 빌드이므로 Windows SmartScreen
   안내가 표시될 수 있습니다.
3. 시작 메뉴에서 "BIXOLON Bakery AI Evaluator"를 실행합니다.
4. 카메라와 모델이 준비될 때까지 기다린 뒤 트레이를 카메라 아래에 놓고
   "분석하기"를 누릅니다.
5. 결과 패널에서 전체 대상, 확정, 알 수 없음, 화면 표시 시간, 모델 추론 시간,
   CPU/GPU 장치를 확인합니다.

결과 해석
---------
- 확정 품목만 품목별 수량에 포함됩니다.
- "알 수 없음"은 등록 품목으로 자동 확정할 근거가 부족한 대상입니다.
- 알 수 없음 대상을 선택하면 확인용 Top-3 후보가 표시됩니다.
- Top-3는 읽기 전용 모델 근거이며 정답률을 의미하지 않습니다.
- 화면 번호와 결과 목록을 선택하면 같은 박스가 함께 선택됩니다.

CPU/GPU
-------
NVIDIA GPU와 호환 드라이버를 사용할 수 있으면 자동으로 GPU를 사용합니다.
GPU를 사용할 수 없거나 초기화에 실패하면 같은 FP32 파이프라인을 CPU로
실행합니다. CPU에서는 첫 모델 준비와 분석 시간이 상당히 길 수 있습니다.
모델은 앱 시작 시 한 번만 불러오고 워밍업하며 분석할 때마다 다시 로드하지
않습니다.

문제 해결
---------
- 카메라를 찾지 못하면 연결 상태를 확인하고 "카메라 다시 연결"을 누릅니다.
- 모델 준비에 실패하면 앱을 종료한 뒤 다시 실행합니다.
- 계속 실패하면 설치 프로그램을 다시 실행해 복구 설치합니다.

제거
----
Windows 설정 > 앱 > 설치된 앱에서 "BIXOLON Bakery AI Evaluator"를 제거합니다.

주의
----
이 프로그램은 모델 성능 평가용 내부 빌드입니다. 라이브 카메라 결과만으로
POS 출하 적합성이나 잠긴 평가셋 정확도를 판단하지 마세요.
